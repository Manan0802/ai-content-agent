# Phase 2 — Media Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the Phase 1 text spine so a completed, human-approved script turns into a playable MP4 — hero/B-roll images (fal.ai two-tier), synced voiceover (Kokoro via the HyperFrames CLI), and a rendered composition (HyperFrames HTML→video) — with one more human gate before the (potentially slow/costly) render actually runs. **No upload yet** — that's Phase 3.

> **Updated 2026-07-06 after a deep research pass** (see spec §6 for the full log). Two findings changed this plan before a line of it was built: (1) the hero-image model is now **FLUX.2 [dev]**, not Instant Character — same fal.ai account, ~8x cheaper, comparable no-fine-tune consistency; (2) India's 2026 IT Rules require **visible + audible AI-content disclosure** on every render, so that's now baked into `composition_writer`/`voiceover_node` from the start rather than bolted on later. Everything else in this plan (HyperFrames as the render tool, Kokoro as the voice, the deterministic-HTML composition approach) was re-confirmed as the right call by that research, not changed.

**Architecture (this phase):**

```
... script_writer → [HITL script]     (Phase 1, unchanged)
  └─ visuals_node        (fal.ai: FLUX.2 [dev] for hero scenes, FLUX.1 schnell for B-roll)
  └─ voiceover_node       (HyperFrames CLI `tts`, Kokoro-82M local, one .wav per segment
                           + one fixed AI-disclosure line synthesized once per video)
  └─ composition_writer   (deterministic HTML per the HyperFrames composition contract;
                           persistent on-screen "AI-Generated" label + disclosure intro clip)
  └─ render_node:
       lint → validate → inspect   (automatic, no human)
       → [HITL render?]            (new checkpoint — render is slow/real work, never silent)
       → `hyperframes render`      (produces outputs/<job_id>/render/final.mp4)
```

**What changed vs. the original spec's Phase 2 wording, and why (all my calls, not yours to referee):**

1. **Voice is not a custom Kokoro integration.** The `hyperframes-media` skill already ships a Kokoro-82M TTS path via `npx hyperframes tts` — zero credentials, always available. Building a second Kokoro wrapper would just duplicate what's already installed. We shell out to the CLI instead (mockable, like the Groq client).
2. **The composition (the HTML HyperFrames renders) is generated by plain Python, not an LLM.** I read the HyperFrames composition contract (`hyperframes-core`) — root needs exact `data-composition-id`/`data-width`/`data-height`/`data-duration`, clips need `data-start`/`data-duration`/`data-track-index`, and `<audio>` must be a **direct child of the root**, never nested inside a scene's `<section>`, or it silently renders with no sound. That's a deterministic mapping from `script.segments` + asset paths → HTML — no creativity needed, so it's unit-testable the same way `script_writer` is, and it can't "forget" the contract the way a freehand LLM-authored composition could.
3. **New `"render"` HITL checkpoint.** The HyperFrames CLI's own convention is "render is user-gated, never auto-render once checks pass" — so this isn't optional polish, it's how the tool expects to be driven. It reuses the same `Notifier` from Phase 1.
4. **BGM, SFX, and per-word animated captions are deferred**, not built in this phase. The audio engine also does background music/sound effects/word-level caption timing, but that's visual/audio polish on top of a pipeline that doesn't exist yet. Get one plain video out end-to-end first; polish is a fast follow-up plan once this works.
5. **Character reference image**: no design exists yet (open item on your side). `CHARACTER_REF_IMAGE_URL` is an env var. If it's empty, hero scenes silently fall back to the no-reference FLUX.1 schnell tier (same as B-roll) and the state records nothing broken — the whole pipeline stays runnable today, and dropping in the real character later is a one-line `.env` change, no code change.
6. **Hero tier is FLUX.2 [dev], not Instant Character** (research-driven change, see banner above) — same fal.ai SDK/account, `~$0.012/MP` vs `~$0.10/MP`, uses multi-reference image conditioning instead of a single `image_url`. The exact fal.ai model slug and reference-image parameter name are **best-guess from research, not yet confirmed against fal.ai's live model catalog** — Task 2 Step 1 now includes a verification step, same pattern as Task 7's CLI-flag verification.
7. **AI-content disclosure is mandatory, not optional polish.** India's 2026 IT Rules require continuous visible labeling + an audible disclosure for AI-generated video, with real penalties (₹50L + criminal liability). `voiceover_node` now also synthesizes one fixed disclosure line per video, and `composition_writer` prepends it as an intro clip plus renders a persistent small on-screen label for the full video duration.

**Tech Stack (added this phase):** `fal-client` (fal.ai Python SDK, reads `FAL_KEY` from env), the `hyperframes` CLI via `npx` (Node.js ≥ 22 + FFmpeg on PATH — required, not yet verified on your machine), no other new Python deps.

## Global Constraints

- Same rules as Phase 1: no agent calls a vendor SDK directly — everything goes through a thin wrapper (`FalClient`, `HyperFramesTTS`, `HyperFramesCLI`) whose I/O method is injectable, so unit tests never touch the network, subprocess, or filesystem beyond `tmp_path`.
- Free-first still holds: Kokoro (not HeyGen/ElevenLabs) is pinned explicitly in the TTS wrapper — no silent upgrade to a paid voice provider just because some unrelated env var happens to be set on your machine.
- Every new node follows the Phase 1 error contract: on failure, append to `state["errors"]` and set safe empty/failed state — never raise out of a graph node.
- This plan does **not** touch `orchestrator/runner.py`'s existing behavior for niches/modes beyond adding the new nodes to the graph.

```python
import os
import fal_client as _fal


class FalClient:
    FLUX2_DEV = "fal-ai/flux-2/edit"
    FLUX_SCHNELL = "fal-ai/flux/schnell"

    def __init__(self, api_key: str | None = None):
        self._api_key = api_key or os.getenv("FAL_KEY")

    def _submit(self, model: str, arguments: dict) -> dict:
        if self._api_key:
            os.environ.setdefault("FAL_KEY", self._api_key)
        return _fal.subscribe(model, arguments=arguments)

    def generate_hero_image(self, prompt: str, reference_image_url: str) -> str:
        result = self._submit(self.FLUX2_DEV, {
            "prompt": prompt,
            "image_urls": [reference_image_url],
        })
        return result["images"][0]["url"]

    def generate_broll_image(self, prompt: str) -> str:
        result = self._submit(self.FLUX_SCHNELL, {"prompt": prompt})
        return result["images"][0]["url"]
```

```python
from orchestrator.state import ContentState
from integrations.fal_client import FalClient


def visuals_node(state: ContentState, fal: FalClient, character_ref_url: str) -> ContentState:
    try:
        assets = []
        for seg in state["script"]["segments"]:
            use_hero = bool(seg.get("character_visible")) and bool(character_ref_url)
            if use_hero:
                url = fal.generate_hero_image(seg["visual_direction"], character_ref_url)
                tier = "hero"
            else:
                url = fal.generate_broll_image(seg["visual_direction"])
                tier = "broll"
            assets.append({"scene_number": seg["scene_number"], "image_url": url, "tier": tier})
        state["visual_assets"] = assets
    except Exception as e:  # noqa: BLE001
        state.setdefault("errors", []).append(f"visuals: {e}")
        state["visual_assets"] = []
    return state
```

```python
import subprocess


class HyperFramesTTS:
    def __init__(self, voice: str = "af_heart", runner=subprocess.run):
        self._voice = voice
        self._run = runner

    def synthesize(self, text: str, output_path: str) -> str:
        cmd = ["npx", "hyperframes", "tts", text, "-o", output_path,
               "--provider", "kokoro", "--voice", self._voice]
        result = self._run(cmd, capture_output=True, text=True)
        if result.returncode != 0:
            raise RuntimeError(f"hyperframes tts failed: {result.stderr}")
        return output_path
```

```python
import os
from orchestrator.state import ContentState
from integrations.hyperframes_tts import HyperFramesTTS


def voiceover_node(state: ContentState, tts: HyperFramesTTS, output_dir: str,
                   disclosure_text: str = "") -> ContentState:
    try:
        os.makedirs(output_dir, exist_ok=True)
        assets = []
        for seg in state["script"]["segments"]:
            path = os.path.join(output_dir, f"scene_{seg['scene_number']}.wav")
            tts.synthesize(seg["voiceover_text"], path)
            assets.append({"scene_number": seg["scene_number"], "audio_path": path})
        state["audio_assets"] = assets

        if disclosure_text:
            disclosure_path = os.path.join(output_dir, "disclosure.wav")
            tts.synthesize(disclosure_text, disclosure_path)
            state["disclosure_audio_path"] = disclosure_path
        else:
            state["disclosure_audio_path"] = ""
    except Exception as e:  # noqa: BLE001
        state.setdefault("errors", []).append(f"voiceover: {e}")
        state["audio_assets"] = []
        state["disclosure_audio_path"] = ""
    return state
```

### Task 6: composition_writer (deterministic HTML per HyperFrames contract)

**Files:** Create `agents/composition_writer.py`; test `tests/test_composition_writer.py`

**Interfaces:**
- `composition_writer_node(state: ContentState, project_dir: str, width: int = 1080, height: int = 1920, disclosure_duration_sec: float = 3.0) -> ContentState`
- Writes `<project_dir>/index.html`: one root `<div data-composition-id data-width data-height data-duration>`.
- If `state["disclosure_audio_path"]` is set (from `voiceover_node`), **prepends** a `disclosure_duration_sec`-long intro `.clip` (simple centered text, e.g. the disclosure text itself) + its `<audio>`, and shifts every scene's `data-start` by that duration — this is the one-time **audible** AI disclosure required by India's 2026 IT Rules.

```python
def composition_writer_node(state: ContentState, project_dir: str,

                f'      </section>'
            )

                f'      <audio data-start="{cursor}" data-duration="{disclosure_duration_sec}" '

            )
```

```python
import subprocess


class HyperFramesCLI:
    def __init__(self, runner=subprocess.run):
        self._run = runner

    def _exec(self, args: list[str]) -> None:
        result = self._run(["npx", "hyperframes", *args], capture_output=True, text=True)
        if result.returncode != 0:
            raise RuntimeError(f"hyperframes {' '.join(args)} failed: {result.stderr}")

    def ensure_project(self, project_dir: str) -> None:
        self._exec(["init", project_dir, "--non-interactive", "--example"])

    def lint(self, project_dir: str) -> None:
        self._exec(["lint", "--cwd", project_dir, "--json"])

    def validate(self, project_dir: str) -> None:
        self._exec(["validate", "--cwd", project_dir, "--json"])

    def inspect(self, project_dir: str) -> None:
        self._exec(["inspect", "--cwd", project_dir, "--json"])

    def render(self, project_dir: str, output_path: str, quality: str = "high") -> None:
        self._exec(["render", "--cwd", project_dir, "--quality", quality, "--output", output_path])
```

```python
import os
from orchestrator.state import ContentState


def render_node(state: ContentState, cli, notifier, project_dir: str) -> ContentState:
    try:
        cli.ensure_project(project_dir)
        cli.lint(project_dir)
        cli.validate(project_dir)
        cli.inspect(project_dir)
    except Exception as e:  # noqa: BLE001
        state.setdefault("errors", []).append(f"render_precheck: {e}")
        state["status"] = "failed"
        return state

    if "render" in state.get("hitl_checkpoints", []) and state["mode"] != "full_auto":
        decision = notifier.ask_approval(
            "Ready to render final video",
            f"Composition passed lint/validate/inspect in {project_dir}. "
            f"Preview with `npx hyperframes preview` before approving if unsure.",
        )
        if decision != "approve":
            state["status"] = "failed"
            return state

    output_path = os.path.join(project_dir, "render", "final.mp4")
    try:
        cli.render(project_dir, output_path, quality="high")
        if not os.path.exists(output_path) or os.path.getsize(output_path) == 0:
            raise RuntimeError("render produced no output")
        state["render_output_path"] = output_path
        state["status"] = "media_complete"
    except Exception as e:  # noqa: BLE001
        state.setdefault("errors", []).append(f"render: {e}")
        state["status"] = "failed"
    return state
```
